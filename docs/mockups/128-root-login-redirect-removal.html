#128 구조·상태 검토 목업

앱 자체 origin 검증용 문서. 공개 weiverai.com/은 별도 랜딩 레포가 담당한다. 이 문서의 설명과 프레임은 실제 앱 페이지 고유 콘텐츠가 아니다.

AC1. 앱 루트 응답·URL 유지

초기 상태: 비로그인 또는 기존 유효 인증. 동작: / 직접 요청 후 새로고침.

AC2. 빈 루트 페이지

아래 프레임 내부는 페이지 고유 콘텐츠가 없는 상태다. 안내문·링크를 추가하지 않는다.

공통 레이아웃의 토스트 기능은 AC7과 같이 유지한다.

AC3. /login 직접 접속·새로고침

pathname /login 유지. 실제 화면은 선택한 탭의 폼 하나만 표시한다.

정적 상태 목업: 탭 버튼은 상태 구분용이다. 신규 로그인 UI·동작 변경을 요구하지 않는다.

AC4. 보호 경로 정상 접근

유효 access token 또는 기존 저장 role과 성공한 토큰 재발급을 전제로 한다.

허용 역할과 기존 렌더링 유지 경로

개인 /onboarding/resume 기존 온보딩 렌더링 동작 유지

기업 인증 가드는 production 서버에서 검증한다. 온보딩 단계 가드는 이번 범위 밖이다.

AC5. 인증 확인·실패

대상: /corporate/dashboard, /applicant/dashboard, /onboarding/resume.

확인 중: 보호 가드 내부 콘텐츠 없음. 재발급 인증 거절 또는 API 오류 후: /login 이동.

공통 레이아웃 전체의 비노출을 요구하지 않는다. 새로운 오류 UI를 추가하지 않는다.
