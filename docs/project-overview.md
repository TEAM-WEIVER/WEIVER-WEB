# Weiver (위버) — AI 채용 매칭 플랫폼

구직자가 서류를 한 번 제출하고 AI 면접을 한 번 완료하면, 기업이 먼저 연락해오는 **역매칭 구조**의 AI 채용 플랫폼.

기업은 수백 개의 서류를 직접 검토하는 대신, AI가 분석한 지원자 리포트를 확인하고 바로 컨택한다.

---

## 사용자 유형

- **기업** (B2B): 채용 공고 등록 → 매칭된 지원자 리포트 열람 → 컨택
- **구직자** (B2C): 서류 제출 → AI 면접 1회 완료 → 기업 제안 수신

---

## 핵심 기능

### 구직자

- 이력서 · 자기소개서 · 포트폴리오 업로드
- AI 화상 면접 진행 (음성, 영상, 텍스트 데이터 수집)
- 매칭 제안 알림 및 리포트 열람

### 기업

- 채용 공고 및 인재상 입력
- 지원자 매칭 리스트 확인 (매칭 점수 순 정렬)
- 지원자별 상세 리포트 열람
  - AI 종합 요약
  - 직무 역량 적합도 (Skill-Fit)
  - 조직문화 적합도 (Culture-Fit)
  - 커뮤니케이션 태도 평가
  - 면접 핵심 발언 하이라이팅
- 지원자 컨택

---

## 기술 스택 (프론트엔드)

- 백엔드 서버와 REST API 통신
- AI 면접: 실시간 화상 스트리밍 (음성 · 영상 · 텍스트 동시 전송)
- 리포트 UI: 정량화된 점수 시각화 (차트, 게이지 등)
- 기업 / 구직자 2개의 독립된 사용자 흐름
