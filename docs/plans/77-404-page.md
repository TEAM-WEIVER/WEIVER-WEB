# [#77] 404 Not Found 페이지

## User Story

US: 사이트 방문자로서, 존재하지 않는 URL에 접근했을 때 명확한 안내와 복귀 수단을 제공받고 싶다. 왜냐하면 빈 화면이나 의미 없는 오류 메시지 앞에서는 다음 행동을 알 수 없기 때문이다.

## Acceptance Criteria

### AC1. 존재하지 않는 경로 접근 시 404 페이지 노출

- Given: 인증 여부와 무관하게 어떤 사용자가
- When: 앱 내에 정의되지 않은 URL 경로(예: `/abc`, `/applicant/xyz`)로 접근하면
- Then: Next.js `not-found.tsx`가 렌더링되어 404 안내 메시지("페이지를 찾을 수 없습니다" 또는 동등한 한국어 문구)와 홈으로 이동하는 버튼이 화면에 표시된다. 초기 직접 접근(SSR) 시 HTTP 응답 상태 코드 404가 반환된다.

### AC2. 홈 복귀 버튼 동작

- Given: 404 페이지가 렌더링된 상태에서
- When: 사용자가 홈으로 이동 버튼을 클릭하면
- Then: `/` 경로로 이동하며, 히스토리 스택 추가를 강제하지 않는다(`replace` 옵션 허용)

<!-- 내부 메모: not-found.tsx는 Server Component 유지 → metadata export 가능, history trap 방지. 구현은 `<Link href="/">` 단일화 -->

### AC3. 정적으로 정의되지 않은 URL 접근 시 공통 404 페이지 적용

- Given: **정적으로 정의되지 않은 URL**(Unmatched URL)에 직접 접근했을 때
- When: Next.js 라우터가 일치하는 세그먼트를 찾지 못하면
- Then: 공통 `src/app/not-found.tsx` 가 렌더링되며, 헤더·푸터 없이 독립적인 레이아웃으로 표시된다

### AC4. 접근성 — 페이지 제목 및 헤딩

- Given: 404 페이지가 렌더링된 상태에서
- When: 스크린리더 또는 브라우저가 페이지를 파싱하면
- Then: 페이지 `<title>`이 "404 | WEIVER"로 설정되고, `<h1>`에 "페이지를 찾을 수 없습니다" 문자열이 포함된다

## API 연동

404 페이지는 순수 프론트엔드 기능으로 백엔드 API 호출이 없다.

> API 스펙 조회 시도 결과: `https://api.piuda.site/v3/api-docs` 서버가 502를 반환하여 접근 불가. 404 페이지 특성상 관련 엔드포인트는 존재하지 않는 것으로 판단.

## 컴포넌트 스펙

- 사용할 shadcn/ui 컴포넌트: `Button` (홈 복귀 CTA)
- 상태 관리 필요 여부: 없음 (정적 페이지)
- 접근성 주의사항:
  - `<h1>`에 "페이지를 찾을 수 없습니다" 명시 (스크린리더 인식)
  - 복귀 버튼은 `<Link href="/">` 사용 (키보드 포커스 및 Tab 이동 가능)
  - 페이지 `<title>`을 "404 | WEIVER" 형태로 설정 (`not-found.tsx`의 metadata export 활용)

## 향후 고려사항

> AC에서 제외한 엣지 케이스

- 인증된 사용자의 경우 역할(지원자/기업)에 따라 각 대시보드로 바로 보내는 스마트 복귀 처리
- `/applicant/**` 하위의 404와 `/corporate/**` 하위의 404를 각 세그먼트별 `not-found.tsx`로 분리하여 맥락에 맞는 안내 문구 제공
- 동적 라우트 세그먼트(`[jdId]` 등)에서 `notFound()` 호출 시 부모 레이아웃 중첩 렌더링 → 별도 세그먼트별 `not-found.tsx` 정책 필요
- 보호 경로(`/applicant/**`, `/corporate/**`) 내 미인증 접근 시 동작: Unmatched URL의 경우 Next.js가 중간 레이아웃을 마운트하지 않으므로 가드가 실행되지 않아 404가 표시됨. 단, 동적 라우트에선 가드가 먼저 실행되므로 로그인 유도가 우선 적용될 수 있음 — 정책 결정 필요
- 잘못 입력된 URL 패턴을 로깅하여 깨진 링크 모니터링 (Sentry 등 연동 시)
- 애니메이션 또는 일러스트 추가 등 브랜드 경험 강화
