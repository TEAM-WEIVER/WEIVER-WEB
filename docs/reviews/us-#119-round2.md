## 기각 / 보류

- agy C-1의 수정 제안 “`setAudioAnswerAccepted` 허용 상태에 `RECONNECTING` 추가 + `prevStatusRef`를 `SUBSCRIBED`로 갱신하는 동기화 인터페이스”는 **채택하지 않았다**. 웹소켓 훅 내부 ref를 외부에서 고치게 되어 결합도가 높아진다. 로컬 phase `waiting`이 store보다 우선한다는 규칙(M1)만으로 화면 고착을 막을 수 있다. 문제 제기 자체는 M1 문구 보완으로 수용했다.
- Minor는 모두 수용했다(최종 수용 여부는 사용자가 결정).
