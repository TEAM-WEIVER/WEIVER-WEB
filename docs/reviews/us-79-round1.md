## Critical

없음

## Major

- [ ] AC7은 사용자 관점의 인수 기준이 아닌 구현 설계 결정(RouteProgressBar를 루트 레이아웃에 마운트)을 AC 형식으로 표현하고 있다. Given이 "레이아웃이 존재한다", When이 "앱이 초기화된다"로 사용자 행동이 없으며, 이는 컴포넌트 스펙 섹션에서 이미 다루고 있는 내용과 중복된다. AC7을 삭제하고 해당 내용을 컴포넌트 스펙의 구현 지침으로 흡수하거나, 사용자 관찰 가능한 결과(예: "모든 페이지에서 공통으로 로딩 바가 노출된다")로 재표현하는 것을 권고한다.

## Minor

- [ ] AC1~AC5 각각의 Then 절에 "자동으로 사라진다"가 이미 포함되어 있어 AC6의 내용이 부분적으로 중복된다. AC6는 시각적 완료 동작(100% 채워진 뒤 페이드아웃, DOM 제거)을 명세하는 역할로 존재 의의가 있으나, 중복 표현임을 인지하고 AC1~AC5의 Then 절에서 "자동으로 사라진다" 부분을 AC6로 위임하는 형태로 정리하면 더 명확하다.
- [ ] AC2에서 "다음(저장)", "나중에 작성", "이전 단계" 세 버튼이 하나의 When에 묶여 있다. 각 버튼의 동작(저장 API 호출 후 전환 vs. 즉시 전환)이 다를 수 있으므로, 향후 구현 중 동작 차이가 발생하면 AC를 분리하는 것을 고려한다.
